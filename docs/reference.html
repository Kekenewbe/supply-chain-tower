9 Patterns OWASP scannés par @securite

  1. SQL_INJECTION — concat dans execute() / query()
  2. SHELL_INJECTION — os.system(), subprocess shell=True
  3. XSS — innerHTML=, dangerouslySetInnerHTML sans sanitize
  4. EVAL_DANGEREUX — eval(, exec(, new Function(
  5. SECRET_HARDCODE — sk-, pcsk_, AKIA, ghp_, xox
  6. PATH_TRAVERSAL — concat chemin sans Path.resolve()
  7. DESERIALISATION — pickle.loads(, yaml.load( sans SafeLoader
  8. REDIRECT_OUVERTE — redirect(req.query.X)
  9. CRYPTO_FAIBLE — md5(, sha1( pour passwords
Bypass : ajouter # security-ok: raison sur la ligne concernée.
