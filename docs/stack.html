Qualité & Standards

OWASP Top 9

9 patterns scannés automatiquement par @securite (hook PreToolUse sur chaque Edit/Write).

Git worktrees

Isolation parallèle de @frontend et @backend.

TDD strict

Tests avant code pour @backend. RED → GREEN → REFACTOR.

WCAG 2.1 AA

Accessibilité obligatoire pour @frontend. Contrast 4.5:1, focus visible, aria-labels.

effort=max

Raisonnement complet forcé sur tous les agents (CLAUDE_CODE_EFFORT_LEVEL=max). Contourne la réduction introduite en mars 2026.

Adaptive thinking désactivé

Budget fixe par tour (CLAUDE_CODE_DISABLE_ADAPTIVE_THINKING=1). Pas de réduction dynamique du raisonnement.

ASCII-only inbox.md

Tous les agents utilisent uniquement ASCII dans inbox.md. Emojis remplacés par [VALIDE] [BLOQUE] [DONE] etc.
