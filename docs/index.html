🏭 Espace_Opti

Usine logicielle IA — De l'idée au MVP livré

Espace_Opti est un espace de travail structuré autour de Claude Code qui orchestre 10 agents IA spécialisés pour produire du logiciel de qualité production. Il ne nécessite aucune connaissance en développement — seulement une idée et la validation des étapes clés. En moins de 30 secondes, un nouveau projet est dérivé du template et prêt à être orchestré.

Concept central

Un template maître (Espace_Opti) est dérivé à la demande par new-project.ps1. Chaque nouveau projet hérite de l'équipe d'agents, des slash commands, des hooks de sécurité et de la mémoire persistante. L'agent @manager orchestre ensuite le cycle complet : PRD → Architecture → Dev parallèle → QA → Simplification → Tests E2E → Livraison.

Prérequis

  • Windows 10/11 — l'automation PowerShell est spécifique à Windows
  • Claude Max — abonnement Anthropic avec usage illimité
  • Python 3.10+ — recommandé : 3.14 (testé)
  • Git for Windows — pour les worktrees des agents
  • Antigravity IDE — fork VS Code, interface principale Claude Code
  • Obsidian — avec plugin Local REST API activé

Quick Start

# 1. Créer un projet dérivé
.\new-project.ps1 "MonProjet"
cd C:\Users\caste\Desktop\MonProjet
.\full.ps1

# 2. Orchestrer (dans Claude Code)
/run-project Je veux créer une app de gestion de factures pour PME
💡 TIP — Le manager posera 8 questions pour cadrer le PRD, puis attendra ta validation avant de lancer l'architecture. Tu n'interviens que sur les décisions stratégiques.
